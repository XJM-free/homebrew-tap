# Quiet Orbit Homebrew Tap

This Tap packages stable, checksum-pinned releases maintained by Quiet Orbit.
Formula changes and bottle publication require human review.

## Install claude-agent-ledger

```sh
brew install XJM-free/tap/claude-agent-ledger
```

The formula reads the same local Claude Code logs as the npm package. Use
`--anonymize` and review subagent and tool names before sharing output.

Homebrew may retain its download cache, the Tap checkout, and the shared `bun`
dependency after uninstalling this formula. The formula does not create or
remove Claude Code logs.
